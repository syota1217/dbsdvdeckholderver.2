# 🐉 DBSDV Deck Builder

Dragon Ball Super Divers デッキ管理・大会記録 PWA

## GitHub Pages デプロイ手順

1. このフォルダの**中身をすべて**GitHubリポジトリにアップロード
2. Settings → Pages → Source: Deploy from a branch → main / /(root) → Save
3. 数分後に `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開

## iPhoneへのインストール

Safari で開いて → 共有 → ホーム画面に追加
